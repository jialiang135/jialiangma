# **不要**把这里的内容合进 requirements.txt —— 它们和主依赖树冲突：

# 互斥。合在一起会让 pip 解析失败，连主依赖都装不上。

# 用法：
#     pip install -r requirements-eval.txt

# 装完后评测功能可用；不装时应用照常运行，执行评测会提示依赖未安装。
#
# 注意体积：ragas 会拖进 datasets / pandas / pyarrow(约 50MB) / instructor
# 等一整套数据科依赖，镜像会显著变大、构建时间明显变长。
# 如果只是演示主流程（问答 + 证据轨 + 朗读），可以不装。

# ⚠️ 为什么全部钉死版本（==）而不是 >= 区间
# ---------------------------------------------------------------
# 本项目的依赖曾经有两类真实故障，都是"松约束 + 无 lock"造成的：
#
# 1. **世代混装**：langchain-core 装到 1.x，而 langchain-openai 是 0.2.x
#    （为 core 0.3 构建）。后果不是报错，而是**静默丢功能**：
#    推理模型的 reasoning_content 在流式路径上被整段丢弃。
# 2. **版本漂移**：本地验证通过的 FastAPI 0.115 / Starlette 0.41 /
#    SQLAlchemy 2.0，在全新环境里会被解析成 0.141 / 1.7 / 2.1 ——
#    容器里跑的是和"验证过的"完全不同的栈。
#
# 因此这里的版本就是**实测通过的那一套**。升级时请整组升，
# 并在本地跑完 `pytest tests/ -q --cov` 与真实端到端验证再改这里。
# ============================================

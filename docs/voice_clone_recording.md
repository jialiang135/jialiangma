# 声音复刻录音指南

给"用你自己的声音朗读回答"这个功能准备录音。照着做完，你会得到一段音频文件，
把它放到公网直链上，就能用 `scripts/tts_enroll.py` 复刻成音色。

> **关于下面这些要求是怎么来的**：阿里云的官方文档页在本机网络策略下打不开，
> 所以时长/格式这类细节我没法逐条引用官方原文。能确定的是 SDK 自己暴露的参数
> （`VoiceEnrollmentService.create_voice(..., max_prompt_audio_length=None)`，
> 默认取 **10 秒**），其余是通用实践。如果你按这个录出来效果不理想，
> 换更长/更短的样本再试是正常调参，不是你操作错了。

---

## 一、先看结论：一句话版本

**找个安静房间，用手机录音机，按下面那段稿子自然地读完一遍，约 40 秒，中间别停。**

---

## 二、录音环境与设备

| 项目 | 要求 | 为什么 |
|---|---|---|
| 环境 | 安静房间，关空调/风扇/窗户，远离马路和冰箱 | 底噪会被一起学进去，以后每次朗读都带着嗡声 |
| 混响 | 选软装多的房间（卧室、衣柜前），别在空房间或卫生间 | 回声会让克隆音发闷、像在桶里说话 |
| 设备 | 手机自带的录音机就够，不必专业麦克风 | 手机麦克风的频响足够复刻用 |
| 距离 | 嘴到麦克风 **15–20 厘米**，略偏一点角度 | 太近会喷麦（p/b 音爆音），太远底噪占比高 |
| 格式 | wav 或 mp3 都行，采样率 ≥ 16 kHz | — |
| 时长 | **30–50 秒**为佳 | SDK 默认只取 10 秒做提示音，给多了它有余地 |

---

## 三、朗读稿

### 怎么读（比读什么更重要）

- **用平常说话的语速和语气**，别端成播音腔 —— 克隆出来的是你读稿时的腔调，
  读得像新闻联播，以后你的分身就一直是新闻联播。
- **一口气读完**，句号处正常换气即可，**不要中途停下来想**。
  停顿会被当成语气的一部分学进去。
- 不要清嗓子、咳嗽、翻纸。**有一次没读好就整段重录**，别剪接拼接。
- 咬字清楚即可，不用刻意用力。

### 稿子（直接照着读）

> 你好，我是这个知识库的主人。平时的工作主要跟人工智能打交道，
> 写代码、做检索、调模型，也踩过不少坑。
>
> 如果你问我最看重什么，那大概是：把东西真正做出来，
> 而不只是停在想法上。
>
> 这几年做过三件事：一个是知识库，一个是多轮对话，还有一个是效果评估。
> 每一件都从头做到底，中间推翻过好几次。

**大约 40 秒。读慢一点、久一点也没关系，读满 30 秒以上就行。**

### 为什么是这段话

不是随便找的一段文字，是按复刻需要挑的：

- **覆盖四声和常见韵母**：`知/主/跟/工/检/索/调/坑/重/真/正/做/推/翻` 等，
  声母韵母分布广，模型学到的发音空间更完整
- **有陈述、有设问、有列举**：三种语气给出了不同的韵律模式，
  以后你的分身念到"第一、第二"时不会一个调子平到底
- **没有生僻字、没有数字、没有英文缩写**：这些最容易读卡壳或读出歧义，
  样本里一旦有瑕疵，瑕疵也会被复刻
- **内容中性且好读**：不需要你理解或思考，照着念就行

## 四、录完先自检

放一遍自己听，确认这四条：

1. **没有喷麦** —— 没听到"噗噗"的气爆声
2. **没有明显底噪** —— 安静段落里没有持续的沙沙声或嗡嗡声
3. **没有破音** —— 音量没顶到失真
4. **没有长时间静默** —— 句子之间停顿不超过 1 秒

有一条不满足，**重录**。样本的问题会一比一复刻到音色上。

## 五、下一步：把文件变成公网直链

`create_voice` 只接受 **http(s) 直链**，本地文件和 DashScope 自己的 `oss://` 都不行
（这一点已实测，详见 `scripts/tts_enroll.py` 顶部说明）。

所以录音还需要放到一个公网可访问的地址。可选方案见聊天里的讨论；
拿到直链后：

```bash
cd personal_agent

# 先测这个地址通不通（建完音色立即删除，不留计费资源）
python scripts/tts_enroll.py enroll --url "你的直链" --name test --test-only

# 通过后正式创建
python scripts/tts_enroll.py enroll --url "你的直链" --name myvoice

# 写入配置（然后重启服务）
python scripts/tts_enroll.py use <上一步输出的 voice_id>
```

`--name` 只能用小写字母和数字，长度小于 10
（例如 `myvoice`、`jia2026`）。

## 六、不满意怎么办

| 现象 | 原因 | 做法 |
|---|---|---|
| 听起来不像你 | 样本太短，或读得太刻意 | 重录，用平常语气、读满 40 秒以上 |
| 有明显底噪/回声 | 环境不达标 | 换房间重录，避开空房间 |
| 语调很平、像机器人 | 样本语调太单一 | 重录时自然些，让设问句和列举句有起伏 |
| 某些字念得怪 | 那类音在样本里出现太少 | 在稿子里补几句包含该发音的日常句子 |

改完样本要**重新创建音色**（`enroll` 一次就是新音色），旧音色用
`python scripts/tts_enroll.py delete <voice_id>` 删掉，避免堆在账号里。
